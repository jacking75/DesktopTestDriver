# DesktopTestDriver 설계·구현 계획 안내

현재 개발 기준은 [GUI 사용 매뉴얼 기반 상세 구현 계획 13번](../docs_working/GUI-사용매뉴얼-기반-상세구현계획-13.md)이다. 이 파일에 있던 초기 계획은 13번 문서로 통합했다. 앞으로 구현 순서·체크박스·완료 조건은 13번 문서에서 관리한다.

- 사용 목적과 완성 버전의 기능은 [README](../README.md)에서 확인한다.
- 간단한 프로그램을 처음부터 끝까지 시험하는 흐름은 [11번 매뉴얼](../docs_working/간단한-GUI-테스트-사용매뉴얼-11.md)을 따른다.
- 작업 PC와 지원자 PC A가 같은 머신인 RemoteAssist 시험은 [12번 매뉴얼](../docs_working/RemoteAssist-E2E-테스트-사용매뉴얼-12.md)을 따른다.
- 실제 명령·요청·응답·오류 처리 형식은 [사용 규약](agent-usage.md)을 따른다.

Controller는 코딩 에이전트와 같은 PC에 두며, Agent는 관측하거나 조작할 각 PC에 둔다. 같은 PC에도 Controller와 Agent를 함께 실행할 수 있다. 시나리오 실행과 제품의 성공·실패 판단은 도구의 책임에 포함하지 않는다.

구현·로컬 검사·실제 PC·두 PC·선택 제품 시험의 완료 여부는 13번 체크 상태와 증거를 각각 따른다.
